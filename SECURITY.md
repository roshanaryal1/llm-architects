# Security policy

This is a research repository: a study corpus, analysis notes, and small standard-library
scripts. It ships no service and stores no user data.

## Reporting

If you find a leaked credential in the history or a supply-chain issue in a dependency, email
**roshanaryaal@gmail.com** with "SECURITY" in the subject. Please do not open a public issue
for credential leaks.

## Supported

Only `main` is maintained.
